# Заливка — обновления

Отсюда программа «Заливка» (заливка карточек чехлов на Wildberries) берёт обновления.
Обновляться не обязательно, любую прошлую версию можно вернуть в «Настройках» программы.

## Установка

1. Скачай последний `zaliv-setup-<версия>.zip` из этого репозитория.
2. Распакуй куда удобно, например в `Документы`.
3. Запусти `Заливка\запуск.pyw`. Откроется страница программы в браузере.

Пока для запуска нужен установленный Python 3 с библиотеками `openpyxl`, `Pillow`, `psd-tools`.

## Что здесь лежит

- `manifest.json` — список версий: номер, дата, что нового, ссылка на архив, контрольная сумма
- `zaliv-<версия>.zip` — архив версии, его качает кнопка «Обновить»
- `zaliv-setup-<версия>.zip` — для первой установки
